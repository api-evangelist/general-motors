# General Motors GraphQL API

General Motors provides connected vehicle APIs through its OnStar and myChevrolet/Buick/GMC/Cadillac platforms. The API covers vehicle diagnostics, remote commands (lock/unlock/start), location data, energy management for EVs, charging status, and vehicle health reports.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from General Motors REST API
**Documentation:** https://developer.gm.com/docs

- Reference: https://developer.gm.com/docs/api-reference
- Schema: https://github.com/api-evangelist/general-motors
